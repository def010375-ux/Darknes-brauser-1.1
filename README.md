# Darknes Tor (Android)

Браузер на движке GeckoView (Firefox): расширения, режим инкогнито, Darknes ID, ИИ-ассистент.

## Как получить APK без компьютера (через GitHub)
1. Создайте репозиторий на github.com (кнопка «+» → New repository).
2. Загрузите в него все файлы проекта (Add file → Upload files), сохраняя папки,
   включая скрытую папку `.github`.
3. Откройте вкладку Actions → «Build APK» → Run workflow.
4. Через 5–10 минут внутри запуска появится артефакт `DarknesTor-apk` — это готовый APK.

## Сборка на компьютере
Откройте папку в Android Studio (JDK 17) и нажмите Build → Build APK.
